Lesson 07 / Search

Grover's search.

Grover's algorithm finds a marked item in an unstructured list in about O(√N) queries.

Start with possibilities

Put the search register into an equal superposition so every item has a chance to be selected.

Oracle and diffusion

The oracle marks the correct answer by changing its phase. The diffusion operator then reflects amplitudes around their average, increasing the marked answer's probability.

Why it helps

After roughly the square root of N iterations, measuring the register is likely to return the target. More iterations can reduce the success probability again.
