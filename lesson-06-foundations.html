Lesson 06 / First algorithms

Foundational algorithms.

Deutsch and Deutsch-Jozsa show how quantum queries can reveal global structure efficiently.

Oracle idea

An oracle is a black-box function. The algorithm can use it, but does not need to know how it is implemented internally.

Deutsch's problem

Deutsch's algorithm decides whether a one-bit function is constant or balanced with one quantum query, while a classical method may need two.

Deutsch-Jozsa

The larger Deutsch-Jozsa problem extends the idea to many input bits. Quantum interference separates the two promised cases efficiently.
